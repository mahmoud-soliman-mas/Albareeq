# البريق - لوحة تحكم الإدارة

هذا المشروع هو لوحة إدارة محلية مبنية باستخدام Next.js App Router و TypeScript و Tailwind CSS.

## التشغيل

1. انتقل إلى مجلد `admin`
2. نفذ `npm install`
3. نفذ `npm run dev`

## بيانات تسجيل الدخول الافتراضية

- البريد الإلكتروني: `admin@albariq.com`
- كلمة المرور: `Admin#2025`

## الميزات

- تسجيل الدخول المحلي مع حماية المسارات
- لوحة بيانات رئيسية
- إدارة خدمات ومحتوى الصفحة الرئيسية
- مكتبة وسائط محلية
- إعدادات الموقع

## ملاحظات

البيانات محلية محفوظة في `localStorage` حالياً، ويمكن ربطها لاحقاً مع Supabase أو Firebase أو Payload CMS عبر `src/services/storage.ts`.
